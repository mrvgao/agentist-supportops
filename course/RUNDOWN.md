# 180 分钟授课流程

课前完成账号登录、依赖下载、模型预热。课堂现场不等待 GPU 库存。

- 00–10 · 10 分钟：从一张工单看完整系统
- 10–25 · 15 分钟：让 Code Agent 获得平台能力
- 25–45 · 20 分钟：GitHub 与 Supabase：先让数据有家
- 45–60 · 15 分钟：Vercel：从仓库到可访问应用
- 60–80 · 20 分钟：Cloudflare 与支付边界
- 90–110 · 20 分钟：Render 与 Daytona：让任务继续运行
- 110–123 · 13 分钟：Agentic DevOps：先让测试变红
- 123–135 · 12 分钟：Agentic DevOps：从绿灯到发布
- 135–155 · 20 分钟：Lambda + vLLM：把模型服务接进来
- 155–165 · 10 分钟：Token 治理：谁可以花多少
- 165–175 · 10 分钟：模型网关与生态选型
- 175–180 · 5 分钟：交付一套可以维护的系统
- 80–90：休息 10 分钟。

每章对应 3 页 slides 和 1 块白板。先提出问题，再让 Code Agent 操作，最后让学员检查验收证据。

断网时使用本地 npm test、既有 CI 截图和静态模型结果；必须标注回放，不能声称现场部署成功。
